Extrahieren — Workflow (korrigiert)

Zuerst schlägt die MinerU-Extraktion die Boxen vor (Phase 1) — danach beginnt die Korrektur Seite für Seite (Phase 2).

flowchart TD
  A["PDF hochladen / Dokument öffnen"] --> B["1 · MinerU-Extraktion
schlägt die Boxen vor
(Segmentierung erkennt Boxen + liest sie → Text)"]
  B --> C["Extrahieren-Seite:
Boxen + Text liegen vor"]
  C --> D["2 · Korrektur beginnt — Seite prüfen"]
  D --> E{"Boxen korrekt?
(Lage · Typ · Vollständigkeit)"}
  E -- nein --> F["Box korrigieren
• ziehen / skalieren (Box wird neu gelesen)
• Typ ändern · Aktivieren / Deaktivieren
• Verbinden / Trennen über Seiten
• Neue Box / Box löschen
• „Diese Box extrahieren“"]
  F --> D
  E -- ja --> G{"Text korrekt?"}
  G -- nein --> H["Text im HTML-Editor korrigieren
(speichert automatisch)"]
  H --> D
  G -- ja --> I["Seite abschließen 🔒
lokale Selbst-Sperre (localStorage) · Status „Abgeschlossen“"]
  I --> J{"Weitere Seiten?"}
  J -- ja --> K["Nächste Seite (◀ ▶ / Raster)"]
  K --> D
  J -- nein --> L["Export → sourceelements.json"]
  D -. "bei Bedarf neu anstoßen" .-> M["„Diese Seite“ / „Alle Seiten extrahieren“
= MinerU erneut laufen lassen"]
  M -.-> D
  C -. "optional, doc-weit" .-> N["Verzeichnisse erkennen → Register-Panel"]
